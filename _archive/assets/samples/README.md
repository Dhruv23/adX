# Samples

Example hardstyle kick one-shots for the Sample Browser (Phase 5) and the
hardstyle auto-generation macro. Filenames encode the kick's root pitch
(e.g. `kick_C3.wav`, `kick_Gs1.wav` = G#1) so pitch-shift-following kicks can
start from a known root — the same distorted, punchy style used by prodArvee,
Hixxy, and Yosuf tracks.

Source: "Harha's Hardstyle Kick Pack 01" by Harha on Freesound
(https://freesound.org/people/Harha/packs/8087/), downloaded as the freely
accessible HQ previews and converted to 44.1kHz WAV. Check the individual
sound pages on Freesound for license terms before redistributing outside this
project.
