# Samples for the example corpus

`stakillaz_demo.adx` plays these two kicks as audio clips (`CLIP samples/kick_C3.wav ...`).
They live beside the examples so the corpus is self-contained: nothing in `docs/examples/`
resolves into `_archive/` (phase_8.md §3.7).

Copied unchanged from `_archive/assets/samples/`. Source: "Harha's Hardstyle Kick Pack 01"
by Harha on Freesound (https://freesound.org/people/Harha/packs/8087/), the freely
accessible HQ previews converted to 44.1 kHz WAV. Check each sound's page on Freesound for
its licence before redistributing them outside this project.
